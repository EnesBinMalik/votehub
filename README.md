# Oy Uygulaması - VoteHub

![Oy Uygulaması - VoteHub — rozet](docs/rozet.svg)

> **Veri analizi · modelleme** — tasarım ve geliştirme: **Enes Öztürk**

---

Kategori bazlı interaktif oylama platformu: Film, Teknoloji ve Spor kategorilerinde kayıtlı kullanıcı oylaması, canlı istatistikler ve detaylı yüzdesel sonuçlar.

## Öne çıkanlar

- Veri temizleme ve hazırlık
- İstatistiksel özet ve görselleştirme
- Modelleme ve tahmin adımları
- Yönetici özeti ve rapor görünümü

## Kurulum ve çalıştırma

```bash
npm install
npm run dev        # http://localhost:3000
```

| Komut | Not |
| --- | --- |
| `npm install` | bağımlılıklar |
| `npm run dev` | geliştirme sunucusu |
| `npm run build` | üretim derlemesi |

## Proje yapısı

```
├── index.html

├── docs/rozet.svg        # imza rozeti
└── src/                  # uygulama kaynakları
```
